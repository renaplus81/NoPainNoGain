# 社畜サバイバル(仮) 基本設計書
 
> 前提: 要件定義書.md の内容をもとに設計する
 
## 1. 概念設計
 
### エンティティ一覧
 
| エンティティ | 説明 | 主な属性(案) |
|---|---|---|
| User | 利用者 | 名前、メールアドレス |
| GamePlay | 1週間サバイバル本体(1人1件) | 開始日時、ステータス(プレイ中/死亡/生存クリア)、死亡日時 |
| Task | 根回しタスク | タイトル、締切、理不尽指数、pointThreshold、pointOperator |
| Condition | 状況フラグ(上司の機嫌など) | 名前、ON/OFF、badSince、bankedPoints |
| OvertimeLog | 残業の記録 | 発生日時、残業時間、どのタスクによるものか |
 
### 関連(リレーションシップ)
 
- User 1 ── 1 GamePlay
- GamePlay 1 ── 多 Task
- User 1 ── 多 Condition
- Task 多 ── 多 Task(前提タスク、自己参照、AND条件)
- Task 多 ── 多 Condition(前提となる状況フラグ、AND条件)
- GamePlay 1 ── 多 OvertimeLog
- Task 1 ── 多 OvertimeLog
