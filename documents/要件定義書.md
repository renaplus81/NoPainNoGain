# 社畜サバイバル(仮) 要件定義書
 
## 1. コンセプト
 
ブラック企業を舞台にした「1週間サバイバルゲーム」。利用者は社畜となり、社畜ポイントが一定値を超えて過労死しないように立ち回りながら、1週間を生き延びることを目指そう。
 
## 2. 要件整理
 
### ゲーム全体のルール
 
1. 制限時間は1週間
2. 唯一の目標は「過労死しない」こと
3. 退職による解決は不可
4. 社畜ポイントが一定のしきい値を超えると、期間中でも即座に死亡してゲームオーバー
5. 1週間生き延びれば生存クリア
6. 同じユーザーが複数回プレイできる
7. スタート画面でタスクの編集・新規作成ができる(ゲームスタート後は一切編集不可)
###　時間の仕組み

- 10時始業、19時定時、22時がその日の上限
-　タスクには「所要時間(duration)」があり、1つ完了するたびにその所要時間のみ進む。スロット制ではなく、時刻を進める方式
- 19時を超えた分が残業時間
- 22時を超えるタスクを選んだ場合、その日は強制的に終了(繰越計算なし※要確認)
- 22時への到達が5回になったら、1週間終了
- 曜日表示は表示のみ、DB設計には含まない
### 社畜ポイントの発生源

```
社畜ポイント = 残業時間 × タスクの理不尽指数
```
 
- 残業時間 = そのタスクの所要時間のうち、19時を超えた分
### タスクの仕組み　
 
- タスクは利用者が持つ、「行動のひな形」で、ゲーム開始前に作成、編集できる
- タスクの完了状態(未完了/完了)は、**プレイ(GamePlay)ごとに独立して管理する**(同じ利用者が複数プレイしても、前回の完了状態は引き継がれない)
- タスク同士の依存関係/前提条件・着手条件の必要ポイントの設定などは、将来追加予定、現在は保留。

### 画面遷移(想定)
 
ログイン画面 → スタート画面(編集可能) → ゲームスタート → (プレイ中) → ゲームオーバー or クリア (→スタート画面)
