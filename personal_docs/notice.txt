ブランチ名って接頭辞つけた方がいいのか

git log --oneline -5 で直近のコミット一覧表示できる(5って何？)

git checkout -b ブランチ名 別のブランチから新しいブランチを作成&移動

一回使ってすでにマージしたブランチは再度使わない。新しいもの作って古いものは捨てなさい

思いがけずちょうどよく繋がることもあるんだな😄
（例：このタスクをやったら残業がなん時間増える、ではなく、タスクの所要時間を持たせることにした→→AIに気付かされたが、「スロット制」(2時間おきに進む)と相性がいいようです。(1タスク=1ターン=2時間、と決まっているなら、「タスクの所要時間」もこの2時間という単位で自然に扱えます)）

なかなかテーブル作れずに概念設計に時間がかかっている、これがいいことか悪いことかがわからない。ただ遅い。
